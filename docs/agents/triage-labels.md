# Triage labels

| Papel | Rótulo | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Aguarda avaliação do mantenedor |
| needs-info | needs-info | Aguarda informações do solicitante |
| ready-for-agent | ready-for-agent | Especificado para execução autônoma |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será executado |

No tracker local, registre o rótulo correspondente em `Status:`.
