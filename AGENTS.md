## Language

Use English for directory names, code identifiers, and commit messages.
Project documentation is written in Portuguese.

## Agent skills

### Issue tracker

Issues vivem em Markdown local em `.scratch/`.
Antes de criar ou atualizar tickets, leia `docs/agents/issue-tracker.md`.

Ao concluir todos os critérios de aceite de um ticket, marque seu `Status:` como
`resolved`, registre o resultado e atualize o índice do esforço antes de encerrar
a tarefa. Registre bloqueios de etapas posteriores nos respectivos tickets;
eles não impedem resolver o ticket concluído. Rótulos de triagem se aplicam aos
tickets ainda não concluídos.

### Triage labels

Usamos os cinco rótulos padrão.
Antes de realizar triagem, leia `docs/agents/triage-labels.md`.

### Domain docs

O projeto tem um único contexto.
Antes de explorar o domínio, leia `docs/agents/domain.md`.
